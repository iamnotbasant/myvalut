# Valut Browser Extension (Manifest V3)

1-Click AI Bookmarking & Knowledge Capture extension for **Chrome, Edge, Brave, Opera, and Arc**.

---

## 🚀 How to Install in 10 Seconds:

1. Open your browser and navigate to:
   - Chrome / Brave / Arc: `chrome://extensions`
   - Microsoft Edge: `edge://extensions`
2. Turn ON **"Developer mode"** (toggle in the top-right corner).
3. Click the **"Load unpacked"** button (top-left).
4. Select the `extension` folder inside this repository:
   ```
   c:\Users\httpb\Desktop\Projects\myvalut\extension
   ```
5. Pin **Valut** to your browser toolbar! 🎉

---

## ✨ Features

- **YouTube 1-Click Integration:**
  - Injects a native **`Valut`** button right next to YouTube's `Share`, `Thanks`, `...` buttons.
  - Injects a bookmark button into YouTube's player control bar.
  - Clicking it extracts the channel avatar, video details, and triggers AI Gemini tagging in the backend.
- **X (Twitter) & Reddit 1-Click Integration:**
  - Adds a seamless bookmark icon on tweet action bars and Reddit posts.
- **Any Web Article / Page:**
  - Press `Alt+V` anytime or click the extension popup to instantly save the page.
- **Direct Cloud & Local Sync:**
  - Communicates directly with your live Valut web app at `https://myvalut.vercel.app/api/extension/save` (and supports local development on `http://localhost:3000`).
